# Changelog

All notable changes to FanucNav will be documented in this file.

## [1.0.0] - 2026-08-28

### Added
- Initial public release of FanucNav for Notepad++
- FANUC TP/LS backup indexing and navigation
- Call graph and label reference browsing
- I/O and table inspection support
- Renumbering helper for TP program maintenance
- Notepad++ XML syntax definition for FANUC TP / LS
- Repository documentation, security policy, and contribution guide

### Changed
- Cleaned repository to keep source-only public distribution focused on the plugin and docs
- Improved README presentation and release packaging

### Fixed
- Corrected README banner asset path for GitHub rendering
- Added clearer project install and troubleshooting guidance
