# Contributing to FanucNav

Thanks for your interest in improving FanucNav.

## How to contribute

1. Fork the repository.
2. Create a feature branch from `master`.
3. Make a focused change with clear intent.
4. Run the relevant build or smoke checks locally.
5. Open a pull request with a short summary and testing notes.

## Coding expectations

- Keep changes narrow and understandable.
- Prefer readable C# code and avoid unnecessary refactors.
- Preserve compatibility with Notepad++ plugin integration.
- Add or update tests when changing parser behavior.

## Pull request checklist

- Include a clear problem statement and solution summary.
- Reference any related issue if applicable.
- Verify the project still builds successfully.
- Keep the diff scoped to the purpose of the change.

## Reporting issues

Use GitHub Issues for bugs, questions, and feature requests. Include:

- Notepad++ version
- Windows version
- FANUC file type involved
- Expected behavior
- Actual behavior
- Any logs or sample snippets when possible

## Community

Please be respectful and constructive in discussions. We welcome improvements to parsing, UI, docs, and compatibility.
