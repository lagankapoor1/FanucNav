# FanucNav

Author: Lagan Kapoor

FanucNav is a Notepad++ plugin for navigating and understanding FANUC robot backup files written in TP/LS formats.

## Features
- Navigate FANUC backup files and program references
- Jump between CALLs, labels, and usages
- Inspect robot data and macro tables
- Renumber TP programs and remap references

## Requirements
- Windows
- 64-bit Notepad++
- .NET Framework 4.8

## Build
```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```
