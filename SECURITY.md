# Security Policy

## Supported versions

The project currently supports the latest repository version on the `master` branch.

## Reporting a vulnerability

Please do not open a public GitHub issue for security vulnerabilities.

Instead, report privately by emailing the maintainer or using the repository's private security reporting channel if one is configured.

Please include:

- a description of the issue
- affected files or components
- reproduction steps if available
- severity and impact assessment
- any suggested mitigation

## Response expectations

We will review reports as quickly as possible and work toward a fix and coordinated disclosure.

## Responsible disclosure

Please allow a reasonable period for a fix before public disclosure, and avoid exploiting any vulnerability beyond what is necessary to confirm the issue.
